# Failure model

- All source frontends validate before committing a revision. Missing/ambiguous anchors, overlapping splices, malformed later hunks and stale UUID/base hashes produce no new head. Syntax-invalid resulting text is a marked draft, never executed.
- `repair` starts at the beginning. After delegation, effects are conservatively `unknown`; no output-text parsing invents rollback or tool success. A committed native write remains committed if a later schema check/diagnostic fails. There is no execution journal, cached result, provider retry, step continuation or command replay.
- Concurrent repairs cannot change a pinned running source. A stale UUID fails; running scratch references are busy. Resource pressure rejects work when protected sources fill the reservation budget.
- Expired/unavailable scratch: `SOURCE_EXPIRED`; removed historical scratch revision: `REVISION_EVICTED`. No content substitution. Promotion to a named buffer is the durable retention route.
- Corrupt source hashes or unsafe owned paths fail closed. The store checks private POSIX modes, ownership, regular-file identity and symlinks. Unknown store files, incomplete crash locks and orphan staging data return recovery-required errors; they are not blindly removed. Retain the entire store and investigate while Pi processes are stopped.
- Completed per-record writes use same-directory rename. This is not a claim of power-loss durability, distributed isolation, NFS safety or complete ACL preservation. Only local Linux source storage is tested. Scratch is explicitly refused on Windows rather than trusting POSIX mode bits there.
- Source-store locks coordinate this plugin only. PID reuse is conservative (may report busy). A hard-killed source owner can be recognized as interrupted; restart never executes source. An ambiguous crash lock/staging artifact may require manual recovery; no general automated recovery UI is implemented.
- Canonical named history is append-only. No retire action shrinks Pi's session file; scratch release does not erase original model arguments or old session events. Source-cache counters are not RSS.
- Workspace mutation status is **not_started / unavailable** in this candidate. No multi-file atomicity, rollback, ACL preservation, writer isolation or file-transaction recovery guarantee is claimed. Pure text plans do not confer filesystem authorization.
